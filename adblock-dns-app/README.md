# 광고차단 DNS 스위치 (안드로이드)

안드로이드의 **개인 DNS**를 광고 차단 DNS(AdGuard DNS)로 켜고 끄는 앱입니다.
VPN을 쓰지 않아서 **VPN을 막는 앱에서도 동작**합니다.

- 안드로이드 9 이상
- 광고 없음, 데이터 수집 없음, 인터넷 권한 없음
- 상단바 빠른 설정 타일 지원

## 설치

1. `dist/adblock-dns-switch-1.0.apk`를 휴대폰으로 옮깁니다.
2. 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 경고가 나오면 해당 앱(파일 관리자 등)에 설치를 허용해주세요.
3. VPN 방식 광고 차단 앱(AdGuard, Blokada 등)이 켜져 있으면 꺼주세요.

## 사용 방법

### 간편 모드 (PC 없이)
앱에서 **"주소 복사하고 설정 열기"**를 누르면 DNS 주소가 복사되고 설정 화면이 열립니다.
설정 → 연결 → 기타 연결 설정 → **개인 DNS** → "개인 DNS 제공업체 호스트 이름" → 붙여넣기 → 저장.

### 원터치 모드 (PC로 한 번만 권한 주기)
안드로이드는 일반 앱이 개인 DNS를 직접 바꾸지 못하게 막아둡니다. PC에서 한 번만 권한을 주면
앱 버튼이나 상단바 타일로 바로 켜고 끌 수 있습니다.

1. 휴대폰 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호를 7번** 눌러 개발자 옵션 켜기
2. 설정 → 개발자 옵션 → **USB 디버깅** 켜기
3. PC에 [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)를 받아 압축 풀기
4. 휴대폰을 USB로 연결하고, 휴대폰에 뜨는 "USB 디버깅 허용"을 승인
5. 압축 푼 폴더에서 명령 실행:
   ```
   adb shell pm grant com.adblockdns.toggle android.permission.WRITE_SECURE_SETTINGS
   ```
6. 앱을 다시 열면 원터치 모드로 바뀝니다. 권한은 앱을 지우기 전까지 유지됩니다.

상단바를 내려 연필(편집) 아이콘 → **"광고 차단"** 타일을 끌어다 놓으면 상단바에서 바로 켜고 끌 수 있습니다.

## 참고
- 보상형 광고("광고 보고 보상 받기")는 차단 중에 동작하지 않습니다. 필요할 때만 잠깐 끄세요.
- 끄기를 누르면 개인 DNS가 기본값인 **"자동"**으로 돌아갑니다.
- 광고가 안 뜨면 아예 작동하지 않도록 만든 앱에는 효과가 없습니다.
- 유튜브처럼 영상과 광고를 같은 서버에서 보내는 경우는 DNS로 막을 수 없습니다.
- 이 APK는 디버그 키로 서명되어 있습니다. 다른 환경에서 다시 빌드한 APK로 업데이트하려면 기존 앱을 지우고 설치해야 할 수 있습니다.

## 직접 빌드

```
echo "sdk.dir=/경로/android-sdk" > local.properties
./gradlew assembleDebug
```
결과물: `app/build/outputs/apk/debug/app-debug.apk`
