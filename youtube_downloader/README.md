# 유튜브 다운로더 (프리미어 프로 / 오디션용) · 윈도우

유튜브 영상을 **프리미어 프로에서 바로 열리는 MP4**로, 또는 **오디션에서 쓰기 좋은 MP3/WAV**로 받는 윈도우용 프로그램입니다.

> ⚠️ 본인이 만든 영상이거나 사용 허락을 받은 영상만 받으세요. 저작권이 있는 콘텐츠를 무단으로 내려받거나 다시 배포하면 저작권법 및 유튜브 약관 위반이 될 수 있습니다.

## 기능

| 구분 | 내용 |
|---|---|
| 🎬 영상 | MP4 (H.264 영상 + AAC 오디오). **프리미어 프로에서 바로 import 가능** |
| 화질 선택 | 최고 / 4K / 1440p / 1080p / 720p / 480p / 360p. "정보 가져오기"를 누르면 그 영상에 실제로 있는 화질만 표시 |
| 자동 변환 | 유튜브의 1440p·4K는 대부분 VP9/AV1 코덱이라 프리미어에서 안 열립니다 → 자동으로 H.264로 변환 (CPU 또는 NVIDIA/Intel/AMD 그래픽카드 가속) |
| 🎵 오디오 | **MP3** (320/256/192/128kbps) 또는 **WAV** (무손실 48kHz/16bit, 편집용으로 추천) |
| 기타 | 재생목록 전체 받기, 저장 폴더 선택, 진행률/속도/남은 시간, 취소, 설정 기억 |

## 설치 & 실행 (처음 한 번)

1. 이 `youtube_downloader` 폴더를 PC의 원하는 곳에 복사합니다. (예: `C:\Tools\youtube_downloader`)
   - GitHub에서 받을 때는 **Code → Download ZIP** 후 압축을 풀면 됩니다.
2. **`실행.bat`** 을 더블클릭합니다.
   - 파이썬이 없으면 자동 설치(winget)를 시도합니다. 설치가 끝나면 `실행.bat`을 **다시** 실행하세요.
     (자동 설치가 안 되면 <https://www.python.org/downloads/> 에서 설치하고, 첫 화면의 **"Add python.exe to PATH"를 꼭 체크**하세요.)
   - 처음 실행할 때는 yt-dlp를 설치하고, 프로그램이 **ffmpeg(약 200MB)** 와 **Deno(약 45MB)** 를 `bin` 폴더에 자동으로 받습니다. 몇 분 걸릴 수 있어요.
3. 다음부터는 `실행.bat`만 더블클릭하면 됩니다. 실행할 때마다 **yt-dlp가 자동으로 최신 버전으로 업데이트**됩니다. 유튜브가 자주 바뀌기 때문에 중요합니다.

> 💡 바탕화면 바로가기: `실행.bat` 우클릭 → **보내기 → 바탕 화면에 바로 가기 만들기**

## 사용법

1. 유튜브 주소를 붙여넣고 **정보 가져오기**를 누릅니다. 제목, 길이, 받을 수 있는 화질이 표시됩니다.
2. 형식을 고릅니다.
   - **영상**: 화질을 고릅니다. `(변환 없음 · 빠름)`이 붙은 화질은 바로 받아지고, `(H.264 변환 필요)`가 붙은 화질은 받은 뒤 변환하느라 시간이 더 걸립니다.
   - **오디오만**: MP3 음질을 고르거나 WAV를 고릅니다.
3. **다운로드**를 누르면 끝나고 나서 저장 폴더를 열어 줍니다.

### 변환이 너무 느릴 때
4K 영상을 CPU로 변환하면 영상 길이보다 몇 배 오래 걸릴 수 있습니다. 그래픽카드가 있다면 **변환 방식**을 NVIDIA(NVENC) / Intel(QSV) / AMD(AMF) 중 해당하는 것으로 바꾸세요. 그래픽카드 가속이 실패하면 자동으로 CPU로 다시 변환합니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `Sign in to confirm you're not a bot` (봇 확인) | **쿠키** 옵션에서 유튜브에 로그인된 브라우저를 고르세요. **Firefox가 가장 잘 됩니다.** Chrome/Edge/Whale은 브라우저를 완전히 종료해야 할 수 있고, 최신 크롬은 쿠키를 못 읽는 경우가 있습니다. 그럴 때는 브라우저 확장 프로그램으로 `cookies.txt`를 내보내서 "cookies.txt 파일 사용"을 고르세요. |
| `HTTP Error 403`, 갑자기 다운로드가 안 됨 | 유튜브가 바뀐 경우입니다. 프로그램을 닫고 `실행.bat`을 다시 실행하면 yt-dlp가 업데이트됩니다. |
| 일부 화질이 안 보임 | `bin\deno.exe`가 있는지 확인하세요. 없으면 프로그램을 다시 실행해 자동 설치하세요. |
| 프로그램이 안 켜짐 | 폴더의 `error.log`를 확인하세요. `.venv` 폴더를 지우고 `실행.bat`을 다시 실행해 보세요. |
| 프리미어에서 소리가 안 나거나 안 열림 | "H.264로 자동 변환" 옵션이 켜져 있는지 확인하세요. 켜져 있으면 결과물은 항상 H.264/AAC MP4입니다. |

## 파일 구성

```
youtube_downloader/
├─ 실행.bat          ← 이것만 더블클릭
├─ app.py            화면(GUI)
├─ core.py           다운로드/변환 로직 (yt-dlp + ffmpeg)
├─ tools.py          ffmpeg·Deno 자동 설치
├─ requirements.txt
├─ bin/              (자동 생성) ffmpeg.exe, ffprobe.exe, deno.exe
└─ .venv/            (자동 생성) 파이썬 가상환경
```

## 기술 메모

- 다운로드 엔진은 [yt-dlp](https://github.com/yt-dlp/yt-dlp)입니다. 포맷 선택 기준은 `res:<선택화질>, fps, hdr:sdr, vcodec:h264, acodec:aac` 순서입니다. 원하는 해상도를 먼저 맞추고, 같은 해상도 안에서는 프리미어 호환 코덱(H.264/AAC)과 SDR을 우선합니다.
- 다운로드가 끝나면 ffprobe로 코덱을 확인해서 H.264/AAC가 아니면 ffmpeg로 변환합니다. 설정은 x264 CRF 18, AAC 320kbps 48kHz, `+faststart`입니다.
- WAV는 PCM 16bit 48kHz로, 영상 편집에서 표준으로 쓰는 샘플레이트입니다.
