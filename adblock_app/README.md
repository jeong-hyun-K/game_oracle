# 광고 차단기 (안드로이드)

앱을 쓰다가 갑자기 튀어나오는 **전면 광고**를 막아주는 안드로이드 앱입니다.
루팅이 필요 없고, 외부 서버로 데이터를 보내지 않습니다.

## 어떻게 광고를 막나요?

앱이 광고를 띄우려면 먼저 광고 서버(예: `googleads.g.doubleclick.net`)의 주소를 찾아야 합니다.
이 앱은 **휴대폰 안에서만 동작하는 VPN**을 켜서 이 "주소 찾기(DNS 질의)"만 가로챕니다.

```
다른 앱 ──"광고 서버 주소 알려줘"──▶ 광고 차단기 ──▶ 광고 서버 목록에 있음 → "없는 주소(0.0.0.0)"
                                                └─▶ 일반 주소           → 실제 DNS(1.1.1.1)에 물어서 그대로 전달
```

- 광고 서버에 연결하지 못하므로 광고가 로드되지 않고, 전면 광고가 뜨지 않습니다.
- VPN이라는 이름이지만 **외부 VPN 서버는 없습니다.** 모든 처리는 휴대폰 안에서 이뤄집니다.
- 웹페이지·영상 같은 실제 데이터는 VPN을 거치지 않고 평소처럼 바로 나갑니다. 그래서 속도와 배터리에 주는 영향이 작습니다.
- 차단 목록: [StevenBlack hosts](https://github.com/StevenBlack/hosts)(약 7만 8천 개 주소, MIT 라이선스)에 국내외 모바일 광고 SDK 주소(`app/src/main/assets/extra_ads.txt`)를 더했습니다.

## 설치 방법

1. APK 파일을 휴대폰으로 받습니다.
   - 저장소의 **Actions** 탭 → "광고 차단기 APK 빌드" → 최근 실행 → 하단 **Artifacts**의 `adblock-apk`를 받습니다. zip 파일이니 압축을 풀면 `app-debug.apk`가 나옵니다.
2. 휴대폰에서 APK를 엽니다. "출처를 알 수 없는 앱" 경고가 나오면, 파일을 연 앱(파일 관리자·브라우저 등)에 **이 출처 허용**을 켭니다.
3. 설치 후 **광고 차단기** 앱을 엽니다.

> 구글 플레이스토어는 다른 앱의 광고를 방해하는 앱을 허용하지 않습니다. 그래서 APK를 직접 설치하는 방식입니다.

## 사용 방법

1. **차단 켜기** 버튼을 누릅니다.
2. 처음 한 번은 "VPN 연결 요청" 창이 뜹니다. **확인**을 누릅니다.
3. 화면이 초록색 **보호 중**으로 바뀌고, 상단에 🔑(VPN) 아이콘과 "광고 차단 중" 알림이 표시됩니다.
4. 이제 다른 앱을 평소처럼 쓰면 됩니다. 차단된 횟수와 주소는 앱 화면에서 볼 수 있습니다.

### 권장 설정 (항상 켜두기)

- **항상 사용 VPN**: 설정 → 연결(네트워크) → 기타 연결 설정 → VPN → 광고 차단기 ⚙️ → **상시 VPN** 켜기
  - 휴대폰이 앱을 정리해도 시스템이 자동으로 다시 켜 줍니다.
  - 주의: "VPN 없이 연결 차단" 옵션은 **끄세요.** 켜면 앱이 꺼진 동안 인터넷이 막힙니다.
- **배터리 최적화 제외**(특히 삼성·샤오미): 설정 → 애플리케이션 → 광고 차단기 → 배터리 → **제한 없음**
- **개인 DNS는 "끄기" 또는 "자동"으로**: 설정 → 연결 → 기타 연결 설정 → 개인 DNS. 호스트 이름을 직접 지정해 두면 DNS 질의가 이 앱을 거치지 않아 차단이 동작하지 않습니다.

## 앱이 이상하게 동작할 때

광고 서버를 막는 과정에서, 일부 앱은 기능이 같이 막히거나 로딩이 오래 걸릴 수 있습니다.

1. 광고 차단기 화면의 **최근 차단된 주소** 목록을 봅니다.
2. 문제가 생긴 앱을 쓴 직후에 차단된 주소를 눌러 **허용**합니다.
3. 허용한 주소는 **허용 목록 관리**에서 다시 삭제할 수 있습니다.

급할 때는 알림창의 **끄기** 버튼으로 바로 끌 수 있습니다.

## 한계 (알아두세요)

| 상황 | 이유 |
|---|---|
| 유튜브·인스타그램 등의 광고는 못 막음 | 광고와 본 콘텐츠를 같은 서버에서 보내서, 광고만 골라 막을 수 없습니다 |
| "광고 보고 보상 받기"가 작동하지 않음 | 보상형 광고도 광고 서버에서 받아오기 때문입니다 |
| 다른 VPN 앱과 동시에 사용 불가 | 안드로이드는 VPN을 하나만 켤 수 있습니다 |
| 크롬의 "보안 DNS"를 켜면 크롬 안의 광고는 안 막힘 | 크롬이 자체적으로 DNS를 처리하기 때문입니다 (크롬 설정 → 개인정보 → 보안 DNS 끄기) |
| 아이폰 미지원 | iOS는 이런 앱에 유료 개발자 계정과 별도 권한이 필요합니다 |

## 개인정보

- 이 앱은 외부 서버로 어떤 기록도 보내지 않습니다.
- 광고가 아닌 주소 질의만 Cloudflare(1.1.1.1)로 전달합니다. 응답이 없으면 Google(8.8.8.8)로 전달합니다. 일반 DNS 사용과 같은 수준입니다.
- 차단 기록은 휴대폰 메모리에 최근 100개만 보관합니다. 앱을 다시 시작하면 지워집니다(누적 횟수만 저장).
- 인터넷 사용은 두 가지뿐입니다: DNS 전달, 그리고 "차단 목록 업데이트" 버튼을 눌렀을 때 GitHub에서 최신 목록을 받는 것.

## 직접 빌드하기 (개발자용)

필요한 것: JDK 17 이상, Android SDK (API 35)

```bash
cd adblock_app
echo "sdk.dir=/path/to/android-sdk" > local.properties   # Android Studio 사용 시 자동 생성
./gradlew testDebugUnitTest   # 단위 테스트 (DNS 패킷 처리, 차단 판별)
./gradlew assembleDebug       # APK 생성 → app/build/outputs/apk/debug/app-debug.apk
```

Android Studio에서 `adblock_app` 폴더를 열어도 됩니다.

### 코드 구성

| 파일 | 역할 |
|---|---|
| `AdBlockVpnService.kt` | 휴대폰 내부 VPN. DNS 질의를 받아 차단하거나 실제 DNS로 전달 |
| `DnsPacket.kt` | IPv4/UDP/DNS 패킷 해석과 응답 패킷 생성 |
| `Blocklist.kt` | 차단 목록 로드·업데이트, 주소 차단 여부 판단 (상위 도메인 포함) |
| `AdBlockState.kt` | 켜짐 상태, 차단 횟수, 최근 기록, 허용 목록 저장 |
| `MainActivity.kt` | 화면 (켜기/끄기, 통계, 최근 차단 주소, 허용 목록) |
| `BootReceiver.kt` | 재부팅 후 자동으로 다시 켜기 |
