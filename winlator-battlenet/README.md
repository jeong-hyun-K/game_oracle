# Winlator Battle.net (원클릭 설치판)

[Winlator](https://github.com/brunodev85/winlator) 11.2(LGPL-2.1)에 **"배틀넷 원클릭 설치"** 버튼을 추가한 수정판입니다.
안드로이드 폰에서 Battle.net(윈도우용)을 설치하고 실행하는 과정을 버튼 하나로 처리합니다.

> 실제 스냅드래곤 기기에서는 테스트하지 못했습니다. 빌드와 APK 내용 검증까지만 마쳤습니다.
> 배틀넷이나 오버워치가 반드시 실행된다는 보장은 없습니다.

## 버튼을 누르면 하는 일
1. 배틀넷 전용 컨테이너 `Battle.net`을 한 번만 만듭니다.
   - 해상도 1280x720, DXVK, Box64 **Stability** 프리셋, FPS 표시
   - 그래픽 드라이버: Adreno GPU이면 **Turnip**, 그 외에는 Winlator 기본값(Vortek)
   - 환경 변수 `WINE_SIMULATE_WRITECOPY=1` (Wine에서 배틀넷 로그인 창이 안 뜨는 문제의 알려진 해결책)
2. 블리자드 공식 서버(`downloader.battle.net`)에서 `Battle.net-Setup.exe`를 내려받습니다. 설치 파일은 APK에 들어 있지 않습니다.
3. 설치 프로그램을 실행합니다.
4. 설치가 끝난 뒤에는 버튼이 **"배틀넷 실행"** 으로 바뀌고, 누르면 런처가 바로 실행됩니다.

## 설치 방법
1. **원본 Winlator가 설치되어 있다면 먼저 삭제합니다.** 패키지명(`com.winlator`)이 같아서 함께 설치할 수 없습니다. 삭제하면 기존 컨테이너도 지워집니다.
2. `Winlator-BattleNet.apk`를 폰으로 옮겨 설치합니다. 설치할 때 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.
3. 앱을 처음 열면 시스템 파일 설치가 진행됩니다. 끝날 때까지 기다립니다.
4. 첫 화면 아래의 **배틀넷 원클릭 설치** 버튼을 누릅니다.
5. 배틀넷 설치 창이 뜨면 평소처럼 설치하고 로그인합니다.
6. 배틀넷에서 오버워치를 설치합니다. 처음에는 그래픽 옵션을 최저로 시작하세요.

## 막혔을 때
| 증상 | 해결 |
|---|---|
| 로그인 창이 검은색 또는 회색 | Tab·Enter 키로 입력해 봅니다. 로그인한 뒤 배틀넷 설정 → 앱에서 "브라우저 하드웨어 가속 사용"을 끄거나 켜 봅니다. |
| 검은 화면이 계속됨 | 앱을 완전히 종료하고 다시 실행합니다. 컨테이너 설정에서 해상도를 낮춥니다. |
| 계속 실패함 | 컨테이너 설정 → Wine 탭에서 Windows 버전을 Windows 7로 바꿔 봅니다. |
| 마우스로 시점이 돌지 않음 | 게임 화면에서 메뉴를 열고 입력 설정의 **Relative Mouse Movement**를 켭니다. |
| .NET 관련 오류 | 시작 메뉴 → System Tools → Installers에서 Wine Mono를 설치합니다. |

## 직접 빌드하기
```bash
export ANDROID_HOME=/path/to/android-sdk   # platforms;android-35, build-tools;35.0.0, ndk;24.0.8215888, cmake;3.22.1
./build.sh
```
`build.sh`는 Winlator 원본(`brunodev85/winlator-app`, 커밋 `2c33741`)을 받아 `battlenet-one-click.patch`를 적용하고 빌드합니다.

## 알아둘 점
- 디버그 키로 서명되어 있습니다. 다른 환경에서 새로 빌드한 APK로 업데이트하려면, 서명이 달라서 기존 앱을 지운 뒤 설치해야 합니다.
- 리눅스(Wine)에서의 배틀넷·오버워치 플레이는 블리자드가 공식 지원하는 방식이 아닙니다. 처음에는 부계정으로 시험해 보세요.
