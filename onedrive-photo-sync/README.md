# 원드라이브 → 구글 포토 사진 옮기기

삼성 갤러리의 원드라이브 동기화가 끝난 뒤에도 원드라이브에 남아 있는 사진·동영상을
**구글 포토로 한 번에 옮겨 주는** 창(GUI) 프로그램입니다.

- 원드라이브 → 구글 포토로 바로 전송합니다. PC에는 전송 중인 파일만 잠깐 임시 저장했다가 지웁니다.
- 중간에 끄거나 끊겨도 **다시 시작하면 남은 파일부터 이어서** 옮깁니다.
- 원드라이브는 **읽기 전용**, 구글 포토는 **추가 전용** 권한만 씁니다. 어느 쪽 사진도 지우거나 바꾸지 않습니다.
- 비밀번호는 프로그램에 입력하지 않습니다. 로그인은 브라우저의 공식 로그인 화면에서 합니다.

## 준비물

1. **파이썬 3.10 이상** — <https://www.python.org/downloads/> (윈도우 설치 시 "Add python.exe to PATH" 체크)
2. 아래 두 가지 **무료 앱 등록** (처음 한 번만, 합쳐서 10분 정도)

> 왜 필요한가요? Microsoft와 구글은 개인이 만든 프로그램이 사진에 접근하려면
> 본인 명의의 "앱 ID"를 발급받도록 요구합니다. 비용은 들지 않습니다.

### A. Microsoft 클라이언트 ID 발급

1. <https://portal.azure.com> 에 원드라이브와 같은 Microsoft 계정으로 로그인
2. 검색창에 **앱 등록**(App registrations) 입력 → **새 등록**
3. 이름: 아무거나 (예: `사진 옮기기`)
4. 지원되는 계정 유형: **개인 Microsoft 계정만** 선택 → **등록**
5. 왼쪽 메뉴 **인증** → 맨 아래 **공용 클라이언트 흐름 허용**을 **예**로 바꾸고 저장
6. **개요** 화면의 **애플리케이션(클라이언트) ID**를 복사

※ "디렉터리가 필요하다"는 안내가 나오면 무료 Azure 계정 가입(카드 인증 필요, 과금 없음)을 먼저 해야 할 수 있습니다.

### B. 구글 클라이언트 ID / 보안 비밀번호 발급

1. <https://console.cloud.google.com> 에 구글 포토와 같은 계정으로 로그인 → 새 프로젝트 만들기
2. **API 및 서비스 → 라이브러리**에서 **Photos Library API** 검색 → **사용**
3. **OAuth 동의 화면** 설정: 사용자 유형 **외부**, 앱 이름·이메일 입력,
   **테스트 사용자**에 본인 구글 이메일 추가
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   → 애플리케이션 유형 **데스크톱 앱** → 만들기
5. 표시되는 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 복사

※ 로그인할 때 "Google에서 확인하지 않은 앱" 경고가 뜨면 **고급 → (앱 이름)(으)로 이동**을 누르세요. 본인이 만든 앱이라 정상입니다.

## 실행

- **윈도우**: `실행.bat` 더블클릭
- **맥 / 리눅스**:
  ```bash
  pip install -r requirements.txt
  python main.py
  ```
  (리눅스에서 창이 안 뜨면 `sudo apt install python3-tk`)

## 사용 방법

1. **1단계**: Microsoft 클라이언트 ID를 붙여넣고 **로그인** → 브라우저에 표시된 코드를 붙여넣고 로그인
2. **2단계**: 구글 클라이언트 ID·보안 비밀번호를 붙여넣고 **로그인** → 브라우저에서 허용
3. **3단계**: 옮길 범위 선택
   - **사진 폴더 전체** (권장): 원드라이브의 "사진" 폴더와 그 아래 모든 폴더. 삼성 갤러리 사진이 여기에 있습니다.
   - **원드라이브 전체**: 모든 폴더의 사진·동영상
   - **직접 지정한 폴더**: 예) `사진/Samsung Gallery`
4. **옮기기 시작** 클릭. 끝나면 구글 포토의 `원드라이브에서 가져옴` 앨범에서 확인할 수 있습니다.

## 알아둘 점

| 항목 | 내용 |
| --- | --- |
| 하루 한도 | 구글 API는 하루 호출 수가 제한되어 대략 하루 9천 장 안팎까지 옮길 수 있습니다. 한도에 걸리면 안내 후 멈추며, 다음 날 다시 시작하면 이어집니다. |
| 구글 용량 | 원본 화질 그대로 올라가며 구글 저장 용량을 사용합니다. 용량이 부족하면 안내 후 멈춥니다. |
| 촬영 날짜 | 구글 포토는 파일 안의 촬영 정보(EXIF)로 날짜를 정합니다. 촬영 정보가 없는 파일(캡처, 메신저로 받은 사진 등)은 옮긴 날짜로 표시될 수 있습니다. |
| 중복 | 이 프로그램은 한 번 옮긴 파일을 기록해 다시 올리지 않습니다. 단, 이전에 다른 방법으로 이미 구글 포토에 올린 사진과는 비교하지 못합니다. |
| 제외되는 파일 | 0바이트 파일, 200MB 초과 사진, 20GB 초과 동영상, 사진·동영상이 아닌 파일 |
| 재로그인 | 구글 앱이 "테스트" 상태면 로그인이 7일 뒤 만료됩니다. 만료되면 다시 로그인하면 됩니다. |
| 원드라이브 원본 | 그대로 남습니다. 구글 포토에서 확인한 뒤 직접 정리하세요. |

옮기지 못한 파일이 있으면 목록이 `문제_파일_목록.txt`로 저장되고, 다음 실행 때 자동으로 다시 시도합니다.

## 저장되는 정보

사용자 홈 폴더의 `.onedrive-photo-sync` 안에 저장됩니다.

- `config.json` — 입력한 클라이언트 ID 등 설정
- `tokens.json` — 로그인 토큰 (다른 사람과 공유하지 마세요)
- `state.db` — 진행 기록 (지우면 처음부터 다시 옮깁니다)

로그인 정보를 지우려면 프로그램의 **로그아웃** 버튼을 누르거나 이 폴더를 삭제하세요.
